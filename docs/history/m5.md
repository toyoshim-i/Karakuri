# M5 — Interface (Technical Implementation Record)

**Status:** Completed and closed on 2026-09-14.
**Exit Condition:** All panel operations described in [`docs/manual/`](../manual/) implemented with zero remaining `plan` badges in the panel column of [`docs/manual/operations.html`](../manual/operations.html) ([ADR-0226](../adr/0226-m5-closes-when-the-manual-is-implemented-and-the-meter-is-progress-rather-than-completion.md)).

---

## 1. Milestone Overview

M5 transformed Karakuri from a headless/CLI prototype into a full-featured real-time desktop GUI console for live visual performance. It delivered:
- A standalone desktop GUI application (`crates/karakuri`).
- An immediate-mode, zero-allocation layout engine (`crates/karakuri-layout`).
- A modular 8-bay VJ console architecture (`crates/karakuri-console`).
- A componentized widget system (cards, chips, slider tracks, editable fields, vector glyphs).
- A unified control descriptor registry (`karakuri-console::control`) mapping 38 interactive probes to tooltips, hotkeys, and operations.
- A dynamic, GPU-cost-budgeted Master Chain effect pipeline (`kind L5`).
- A comprehensive multi-level keyboard navigation and focus ladder.

---

## 2. Core Architectural Foundations

### Standalone Application Binary (`crates/karakuri`)
- Extracted the GUI window loop and WGPU presentation runtime from `karakuri-cli` into a dedicated application binary (`crates/karakuri`, [ADR-0214](../adr/0214-the-program-moves-out-of-the-cli-and-two-thin-binaries-sit-over-it.md)).
- Extracted runtime environment services (file watching, audio devices, MIDI mappings, setfile bundles) into `crates/karakuri-environment` ([ADR-0215](../adr/0215-the-package-is-karakuri-environment-and-a-module-belongs-if-what-it-deals-with-is-outside-this-process.md)).

### Immediate Layout Engine (`crates/karakuri-layout`)
- Implemented an arithmetic tree constraint solver that solves panel boundaries to pixel-aligned rectangles with zero GPU dependencies ([ADR-0156](../adr/0156-the-consoles-arrangement-is-a-tree-this-repository-owns.md)).
- Independent two-bit visibility flags for operator-folded and drawer-aside states ([ADR-0183](../adr/0183-a-node-is-out-of-the-layout-for-two-reasons-and-they-are-two-bits.md)).
- Persistent window arrangements saved to and recalled from JSON (`arrangements/<name>.arrangement.json`, [ADR-0221](../adr/0221-an-arrangement-is-named-by-the-operator-and-kept-in-a-fourth-place.md)).

### Unified Operation Vocabulary
- All user and agent actions defined in zero-dependency enum `Operation` in `crates/karakuri-operation` ([ADR-0180](../adr/0180-the-operation-vocabulary-is-a-crate-with-no-dependencies.md)).
- Direct translation into disk-serializable session event records in `crates/karakuri-operation-record` ([ADR-0194](../adr/0194-where-an-operation-becomes-a-record-is-a-crate-that-depends-on-both.md)).
- Safety gate in `crates/karakuri-operation/src/gate.rs` regulating MCP agent execution permissions ([ADR-0235](../adr/0235-mcp-reaches-every-operation-and-what-could-stop-the-show-is-refused-until-the-operator-opens-it.md)).

## 3. Modular Console Bays

The console is partitioned into modular bays under `crates/karakuri-console/src/view/`:

### Program Bay (`view/program.rs`)
- Central composited output display with aspect-ratio-preserving letterboxing.
- Four deck preview monitor cells (A–D) continuously displaying channel auditions.
- Geometric area decider for automatic Below/Beside arrangement switching ([ADR-0239](../adr/0239-the-program-bay-preserves-preview-size-when-arranging-beside.md)).
- Risk badge displaying five-tier GPU budget load estimates ([ADR-0298](../adr/0298-the-badge-is-the-band-of-the-number-the-governor-spent-and-how-it-was-taken-crosses-the-seam-undrawn.md)).

### Mixer Bay (`view/mixer/`)
- Channel strips per deck containing trim, opacity fader, blend mode button, mask mini, and peak level meter (`view/mixer/strip.rs`).
- Transition row with wipe shape selector, timing quantum selector, transition length, and `go` trigger capsule (`view/mixer/transition.rs`).
- No crossfader: mix levels are driven directly by channel faders ([ADR-0233](../adr/0233-the-consoles-mixer-has-no-crossfader.md)).

### Transport Bay (`view/transport/`)
- Beat grid visualizer, tempo readout (BPM), and frame rate/cost telemetry (`view/transport/tempo.rs`).
- Audio input device selector card and recording status (`view/transport/audio_in.rs`).
- Latency tracker and offset slider (`view/transport/tracker.rs`).
- Arrangement layout selector, persistence menu, and MIDI learn trigger (`view/transport/arrangement.rs`).
- Exposure / tone-mapping controls (`view/transport/look.rs`).

### Library Bay (`view/library/`)
- Scope selection: Sets, Presets, History, and Folders (`view/library/scopes.rs`).
- Query filtering by text and kind chips (`view/library/filters.rs`).
- Set and procedure row listings, context menus, and procedure reading blocks (`view/library/listing.rs`).
- Automatic archiving of overwritten shipped presets with timestamped backups ([ADR-0347](../adr/0347-the-shipped-library-replaces-its-own-row-and-the-copy-it-replaces-is-kept.md)).

### Inspector Bay (`view/inspector/`)
- Deck and pane target selection, deck naming (`view/inspector/header.rs`).
- Parameter sliders and sensor source binding (`view/inspector/params.rs`).
- Node wiring graph, renderer hierarchy, and connection cards (`view/inspector/wiring.rs`).

### Master Bay & Dynamic Chain (`view/master.rs`)
- Dynamic `kind L5` post-processing chain ([ADR-0340](../adr/0340-kind-l5-is-written-and-the-master-chain-is-an-ordered-list-of-them.md), [ADR-0348](../adr/0348-the-master-chain-is-drawn-in-slots-cut-is-set-through-the-parameter-row.md)).
- Per-slot parameter rows, `retains` cut toggles, slot removal buttons (`−`), and `+ add` chooser from library L5 procedures.
- Drag-and-drop appending of L5 procedures directly onto the chain list ([ADR-0352](../adr/0352-the-chains-list-is-the-master-bays-items-and-a-slot-is-taken-out-by-a-glyph-on-its-row.md)).
- Integrated engine frame cost estimation and governor budget reservation ([ADR-0349](../adr/0349-the-chain-is-the-frames-so-it-reads-the-session-clock-and-is-charged-against-the-frames-budget.md)).

### Sequencer Bay (`view/sequencer.rs`)
- Modulation lane generation, step triggers, and pattern playback mapped to parameter targets ([ADR-0322](../adr/0322-a-sequencer-lane-reads-patterns-and-the-strip-is-one-of-its-targets.md)).

### Staging Bay (`view/staging.rs`)
- Candidate Set cards, hot-swap compilation status, and compile diagnostic displays.

## 4. Interaction & Control Subsystems

### Componentized Widget Architecture (`view/widgets/`)
- **Cards (`widgets/card.rs`)**: Standardized 8px-radius drop-shadowed panel and popup cards (`bay_card`, `popup_card`, `card_row_text`).
- **Chips & Badges (`widgets/chip.rs`)**: Capsule chips, residency tallies, layer badges, and scope tabs (`badge`, `toggle_chip`, `scope_tab`, `tally_into`).
- **Slider Tracks (`widgets/track.rs`)**: Continuous slider tracks with hairline strokes and gradient fills (`slider_track_into`).
- **Text & Filter Fields (`widgets/field.rs`)**: Capsule filter fields and editable text inputs with caret handling (`filter_field`, `editable_text_field`).
- **Glyphs (`widgets/glyph.rs`)**: Vector chevrons, expand arrows, and geometric markers (`chevron_down`, `arrow_mark`).

### Control Descriptor Registry (`karakuri-console::control`)
- Strongly typed `ControlId` enum with 38 variants corresponding to all interactive hit-test probes.
- Static registry `DESCRIPTORS: [ControlDescriptor; 38]` linking each control to its probe name, human-readable label, default hotkey, and bound operation title.

### Focus Ladder & Keyboard Navigation (`crates/karakuri-console/src/focus.rs`)
- Full keyboard traversal across all console regions, deck heads, parameter sliders, cards, and modal popups.
- Hierarchical address ladder allowing `enter` to open cards, arrow keys or digits to select items, and `esc` to climb levels without quitting the app ([ADR-0332](../adr/0332-the-consoles-focus-is-an-address-in-its-tree-and-tab-walks-it.md), [ADR-0350](../adr/0350-the-transports-two-cards-are-walked-and-the-tempo-figure-steps-by-a-beat-a-minute.md), [ADR-0351](../adr/0351-the-lane-chooser-is-a-rung-of-the-address.md)).
