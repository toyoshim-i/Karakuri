## 1. Technical Implementations Delivered

### Deliverable 1: Left-Pane Prompt Bay Architecture & Console Integration
- **Layout & Panel Partitioning (`crates/karakuri-console/src/room`, `layout`)**:
  - Integrated `prompt` bay at the bottom of the left pane alongside `library` and `staging`.
  - Allocated baseline dimensions (~240px default height, ~120px min height) with flex redistribution alongside Library.
  - Fully integrated into console bay grammar (ADR-0343, ADR-0364): retains 27px title bar on collapse, renders standard 6-dot menu dice, supports double-click folding on header, and keyboard `Space` folding.
- **Head & Bay Interaction**:
  - Bay header features interactive CLI preset selector pill (`[ Prompt ▾ ]` or active tool name).
  - Clean visual separation with palette-driven border lines and status indications.

### Deliverable 2: Multi-Session Detached PTY Multiplexer & Process Lifecycle
- **Detached PTY Session Manager (`crates/karakuri-console/src/view/prompt/session.rs`)**:
  - Asynchronous background PTY process spawning via `portable-pty` without stalling UI frame rendering or GPU compute passes.
  - Non-blocking stdout/stderr reader thread continuously buffering terminal output into per-session scrollback buffers (1024-line capacity).
  - Multi-session concurrency: switching active CLI sessions keeps background processes alive without termination (e.g. running Claude while checking logs via a custom shell).
- **Process Exit Handling & Custom Shell Fallback**:
  - Automatic process exit detection cleans up PTY child handles and returns the bay selection to unselected state with a cleared terminal screen.
  - Custom command fallback (`default_custom_command`): defaults to `sh` on Unix/macOS and `powershell` on Windows, immediately spawning an interactive shell when custom is selected without manual command entry.

### Deliverable 4: Cursor-Anchored Native Input with Japanese IME & Multi-Line Support
- **Cursor-Anchored Input Architecture (`crates/karakuri-console/src/view/prompt/paint.rs`, `state.rs`)**:
  - Terminal-cursor-anchored, borderless `egui::TextEdit::multiline` dynamically positioned at exact terminal coordinates `(cursor_x, cursor_y)`.
  - Seamless native OS IME integration (macOS and Windows) for Japanese and multilingual prompt drafting with candidate window anchored accurately to the cursor.
  - Full multiline prompt composition, code snippet pasting, and line break editing before forwarding to PTY `stdin`.
- **ANSI Terminal Emulation & Display Fidelity**:
  - Supports 24-bit Truecolor (`\x1b[38;2;r;g;bm` / `\x1b[48;2;r;g;bm`) alongside standard 16-color ANSI palettes.
  - Relative cursor horizontal and vertical positioning (`\x1b[...D`, `\x1b[...C`, `\x1b[...A`, `\x1b[...B`).
  - Alternate screen buffer switching (`\x1b[?1049h` / `\x1b[?1049l`).
  - Raw line feed (`\n`) positioning honoring current column without premature carriage returns, ensuring perfect CLI banner alignment.
  - Dynamic cursor visibility control (`\x1b[?25h` / `\x1b[?25l`).

### Deliverable 5: Console Focus Ladder & Keyboard Capture Mode
- **Focus Hierarchy & Capture Mode (`crates/karakuri/src/app/handler/key.rs`, `crates/karakuri-console/src/view/prompt/`)**:
  - Smooth ladder transition: global navigation (`Tab`, `Shift-Tab`, `Esc`, `Enter` descent) into terminal input capture mode.
  - In capture mode, keyboard shortcuts are trapped and forwarded directly to the PTY (allowing arrow keys, single-letter confirmations, `Ctrl+C`, `Ctrl+D`).
  - `Tab` navigation remains available to traverse bays; `Esc` releases input capture back to bay level navigation.
