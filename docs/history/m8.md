## 1. Technical Implementations Delivered

### Deliverable 1: Low-Latency Audio Signal Bus & Multi-Band Procedural Modulation
- **Signal Bus Vocabulary Standardisation (`karakuri-signal::id`)**:
  - Extended `SignalId::resolve` to support both explicit `audio.*` namespace prefixes (e.g. `audio.energy`, `audio.onset`, `audio.band0`..`audio.band7`) and semantic spectral band names.
  - Added semantic band resolution mapping to 8 log-spaced frequency bands (40 Hz – 16 kHz):
    - `sub` / `audio.sub`: Band 0 (~40–85 Hz, kick fundamental, sub-bass)
    - `bass` / `audio.bass`: Band 1 (~85–180 Hz, bassline body, punch)
    - `low_mid` / `lowmid` / `audio.low_mid`: Band 2 (~180–380 Hz, warmth)
    - `mid` / `audio.mid`: Band 3 (~380–800 Hz, snare crack, lead melody)
    - `high_mid` / `highmid` / `audio.high_mid`: Band 4 (~800–1700 Hz, clarity)
    - `presence` / `audio.presence`: Band 5 (~1700–3600 Hz, articulation)
    - `brilliance` / `audio.brilliance`: Band 6 (~3600–7500 Hz, sizzle)
    - `air` / `high` / `audio.air` / `audio.high`: Band 7 (~7500–16000 Hz, hi-hat shimmer)
- **Typed Audio Measurements & Accessors (`karakuri-signal::measured`)**:
  - Added named band index constants (`AudioFrame::SUB`, `AudioFrame::BASS`, `AudioFrame::MID`, `AudioFrame::AIR`, etc.) and ergonomic accessors (`sub()`, `bass()`, `mid()`, `air()`, etc.).
  - Preserved determinism and zero-allocation frame boundaries: audio measurements continue to pass across thread boundaries as lightweight `Copy` structures latched once per render frame.
- **Acoustic Frequency Partitioning Validation (`karakuri-audio::analysis`)**:
  - Formally documented the 8 acoustic frequency boundaries in `band_bins`.
  - Added acoustic verification tests asserting that pure sine waves injected across the audio spectrum activate their precise semantic band targets.
- **End-to-End Parameter Modulation & Replay (`karakuri-engine`, `karakuri-environment`)**:
  - Verified that Set bindings (`Binding`) sampling `audio.*` and semantic band names seamlessly modulate GPU uniform buffers through transfer curves and confidence blending.
  - Verified that audio signal bindings survive `.kset` authoring serialization, save/load, and replay journals byte-for-byte.
- **Audio-Reactive Reference Implementation (`examples/audio_bloom.kir`, `examples/audio_bloom.kset`)**:
  - Authored a multi-band audio-reactive procedural shader responding to sub-bass kicks, mid-range harmonics, high-frequency transients, and onset bursts.

### Deliverable 2: Output Plugin Sinks & Decoupled Discovery Architecture
- **Generic GPU Surface Sinks (`karakuri-engine::plugin_sink`)**:
  - Decoupled GPU presentation pipelines to export generic hardware surfaces (`IOSurface` on macOS, `DXGI` shared handles on Windows).
  - Preserved high-performance Vulkan backend on Windows via `wgpu-hal` NT shared handle interoperability.
- **Self-Reporting Discovery Protocol**:
  - Replaced hardcoded plugin names with ndjson self-identification protocol (`Hello { name, kind, surfaces }`).
  - Added principled discovery lookup (`places::plugins`) supporting checkouts, bundles, system prefixes, and custom directories.
- **Platform Binaries & Developer Automation**:
  - Delivered macOS `karakuri-syphon` plugin and Windows `karakuri-spout` plugin with automated build and installation via `scripts/plugins.sh` ([ADR-0358](../adr/0358-the-projector-is-fullscreened-by-the-operating-system-on-the-display-it-is-on-and-another-application-is-reached-through-a-plugin.md)).

### Deliverable 4: Hardened Keyboard Navigation, Tooltip Learning & Unified Bay Headers
- **Bay-Scoped Flat Keyboard Navigation**:
  - Standardized global navigation to `Tab`, `Shift-Tab`, and `Esc`, with `Enter` descending into bay controls.
  - Bound `Space` unconditionally to fold/unfold the focused bay.
- **Interactive Key Learning & Tooltip Synchronization**:
  - Interactive key learn mode (`● Press key (Esc)`) from tooltips, persisting to `<store>/keymaps/default.keymap`.
  - Dynamic `Global` toggle promoting bay shortcuts to global scope with collision detection.
- **Unified Bay Header Interaction & Fold Affordance (ADR-0364)**:
  - Preserved 27px header bar height on folded bays, preventing sibling overlap while retaining hit-testability.
  - Uniform 6-dot menu dice (`⋮⋮`) across all 7 bay heads, reserving click action for the upcoming Bay Context Menu.
  - Double-clicking any bay header bar toggles folding/unfolding.
