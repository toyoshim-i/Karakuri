## 1. Milestone Overview

M6 removed the last synchronous GPU work from the render thread, made a recorded session carry
the deck it ran on, and closed the two sequencer gaps the console had carried as notes. Every
item was either built or settled by a record; nothing was carried forward under this heading.

## 2. Built

### The master chain compiles on a thread of its own (`karakuri-engine::chain_swap`)
- A named worker `karakuri-chain` takes a `ChainSwap` request with a cloned device and queue,
  compiles the slots, builds `ChainTargets` against a `ChainWorkshop` taken from the `Present`,
  flushes before handover, and the frame loop installs the newest finished build with `try_recv`
  at `begin_frame`, before the encoder exists. The outgoing chain is retired to the worker for
  dropping ([ADR-0354](../adr/0354-a-chain-is-compiled-on-a-thread-of-its-own-and-lands-at-a-frame-boundary.md), on [ADR-0033](../adr/0033-freeing-on-the-render-thread-is-the-same-invariant-as-allocating.md)'s terms).
- The params-only path stays a `write_buffer`; the offline PNG loop keeps the synchronous
  `install_chain`. A source scan holds both live hosts to `apply_chain`.

### A swapped-in Set arrives with its own estimate (`karakuri-engine::swap`, `estimate`)
- The build worker runs `estimate` after `measure`; `Built` carries it and the install keeps it,
  re-read at the slot's viewport. `Estimate::at(target)` re-fits the rungs on the record, so a
  resize moves the number without a draw ([ADR-0356](../adr/0356-the-worker-estimates-what-it-built-and-an-estimate-is-a-fit-rather-than-a-number-at-one-size.md)).

### A session head says what the deck held (`karakuri-environment::session`)
- The head is everything before the first tick that is not a frame's own measurement: slot 0's
  Set file, a `procedure` record per node for every other occupied slot, and the deck's state at
  frame 0 written always. `session::head` is the one writer; both programs go through it.
  `--replay` sizes the deck from the head and applies the opening before the first frame
  ([ADR-0355](../adr/0355-a-session-head-says-what-the-deck-held-in-the-records-that-already-say-it.md); ir-spec *The head — what the deck held at frame 0*).

### ADR-0323's refusal is called (`karakuri-operation-record`, `karakuri-pattern`)
- `Current::lanes` carries which lanes hold which controls, filled by both surfaces from
  `Pattern::held()`; `written` answers `Written::Refused` for `FadeDeck`, `Crossfade` on either
  end and `Wipe` on the deck arriving, in one sentence naming the lane. The GUI's MCP reply
  carries that sentence (`not_performed`), the same string `karakuri-cli --mcp` answers.

### A lane can be taken out of a pattern
- `Operation::RemoveLane { pattern, lane }`, `Pattern::remove`, a minus glyph on the lane's row,
  `enter` on the lane, a sixth row on the operations page
  ([ADR-0357](../adr/0357-a-lane-is-taken-out-by-a-glyph-on-its-row-and-enter-on-the-lane-is-the-key.md)).

### The hover layer under a modal overlay
- `Hover::paint` forgets the rest when `View::has_modal_overlay` says a card is down, so a tip
  already up goes on the frame the card is drawn on; all nine overlays are tested.

## 3. Settled by record, not built

- Fade and crossfade keybindings and panel cells: `gap` by decision ([ADR-0353](../adr/0353-a-scheduled-fade-is-not-drawn-on-a-real-time-surface-so-the-two-rows-read-gap-in-both-hand-columns.md)).
- A candidate judged against the deck's period: refused ([ADR-0313](../adr/0313-a-candidate-is-judged-on-its-own-cost-and-the-decks-period-is-a-deck-level-alarm.md)).
- A projector frame loop of its own: refused ([ADR-0166](../adr/0166-the-engines-frame-and-the-panels-are-one-submission.md)).
- Fullscreen on a chosen display: the operating system's gesture on the display the window is
  on; other applications through plugin sinks ([ADR-0358](../adr/0358-the-projector-is-fullscreened-by-the-operating-system-on-the-display-it-is-on-and-another-application-is-reached-through-a-plugin.md)).
- The transport row's frame figure: the CPU's, labelled `cpu` ([ADR-0359](../adr/0359-the-transport-rows-frame-figure-stays-the-cpus-and-says-so.md)).
- `over_budget` as a deck total: nothing new; the band dots, the rate and the CPU figure are the
  instrument ([ADR-0360](../adr/0360-over-budget-stays-the-live-slots-sum-and-no-deck-total-is-drawn.md)).
