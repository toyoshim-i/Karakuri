Karakuri · the manual

Every operation, and every way in

The first rule says every operation that changes something is reachable from the panel, from the keyboard alone, from a mapped MIDI control, and from a model over MCP — and leaves an operation that only asks to each way in's own design. Every operation is a row, every surface is a column, and the badge says whether that surface reaches it. Hover or focus an operation's name for what it does.

How to read a row

built — this surface reaches it today designed — this surface is meant to reach it and does not yet nothing — this surface cannot reach it at all
immediate it lands when you ask for it grid it is scheduled and lands on a musical instant launch the only way in is a flag, before the run on a worker it is built off the render thread and lands when it is ready
read it only asks, so a column left empty here is that way in's own design and not something owed
