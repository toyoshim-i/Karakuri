# `capacity` is a dial, and not part of what a procedure is

An artifact declares a range with a default; the running system chooses within it, and the
ambient is a uniform, so changing it costs a fork but no compile. An artifact records cost **per
element**, which is the intrinsic figure; any capacity's cost is a multiplication.

**What it rules out.** Baking a capacity into the artifact. The 65536 and the 262144 version of
one procedure would hash differently and carry different previews, and the library — which is
the asset — multiplies by every size anyone ever wanted.

**And a caution that is not a licence.** In a procedure with no `spawn` block, `capacity` is also
a **visual** parameter, because `seed` is the initial slot index there and `seed % 512u` builds a
lattice. Derive structure from the ambient (`uint(sqrt(float(capacity)))`) rather than assuming a
size.

**Where it holds.** [ir-spec.md](../ir-spec.md), "capacity / topology". Decided in
[ADR-0009](../adr/0009-capacity-is-a-dial-not-part-of-a-procedures-identity.md).
